# Branding

Plaats hier het officiële logo zodra het beschikbaar is.

- Bestandsnaam: `logo.svg` (voorkeur) of `logo.png`.
- Gebruik de **witte (negatieve) variant**: het logo staat op de donkerblauwe balk bovenin.
- Hoogte in beeld: ca. 40 px. Een SVG blijft op elk scherm scherp; een PNG liefst minimaal 400 px breed.
- Gebruik je een andere bestandsnaam? Pas dan `logoPath` aan in `js/config.js`.

Zolang hier geen logo staat, toont de app de organisatienaam als nette tekst.

`favicon.svg` is het kleine icoon in het browsertabblad.
