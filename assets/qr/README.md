# QR-codes

QR-codes als afbeelding, bijvoorbeeld `snack-01.png`.

- Maak de QR-code vooraf met een betrouwbare generator; de app genereert zelf niets en gebruikt geen internet.
- Formaat: PNG of SVG, vierkant, minimaal 600 x 600 px, met witte rand (quiet zone).
- Test iedere QR-code met twee verschillende telefoons.
