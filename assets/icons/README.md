# Iconen voor snacks

Neutrale iconen die je per snack kunt kiezen via het veld `icon` in `data/snacks.js`.

| Bestand | Beeld |
|---|---|
| icon-spark.svg | Fonkeling |
| icon-chat.svg | Chatberichten |
| icon-document.svg | Document |
| icon-checklist.svg | Actielijst |
| icon-search.svg | Zoeken / onderzoek |
| icon-calendar.svg | Agenda / vergadering |
| icon-mail.svg | E-mail |
| icon-table.svg | Tabel / spreadsheet |
| icon-lightbulb.svg | Idee / tip |
| icon-people.svg | Klant / team |
| icon-pencil.svg | Schrijven |
| icon-cloche.svg | Snackbar (standaard) |

Eigen icoon toevoegen: SVG, vierkant (bijv. 48 x 48), donkerblauwe lijnen (#101D4F)
op transparante achtergrond. Ontbreekt een icoon, dan toont de app automatisch een standaardicoon.
