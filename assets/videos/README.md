# Demovideo's

Plaats hier de demovideo's, bijvoorbeeld `snack-01.mp4`.

- Formaat: MP4 (H.264-video, AAC-audio), 1920 x 1080 of 1280 x 720, 16:9.
- Duur: 1 tot 3 minuten.
- Optioneel ondertitels: `snack-01.nl.vtt` (vul het veld `captions` in).

Zie `docs/CONTENT-GUIDE.md` voor alle richtlijnen. Gebruik uitsluitend fictieve of geanonimiseerde gegevens.
