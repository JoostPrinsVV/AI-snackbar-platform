# AI Snackbar

Digitale snackkaart met korte AI-demo's voor de Boost & Learn (26 & 27 oktober 2026), Visser & Visser.

Dit is een statische website (HTML, CSS, JavaScript), live via GitHub Pages. Alle demo-inhoud is fictief.
Instellingen staan in `js/config.js`, de snacks in `data/snacks.js`, de HTML-demo's in `assets/demos/`.
De handleidingen (o.a. Supabase en tablets) staan in het volledige projectpakket, niet in deze repository.

De promptpagina voor de QR-codes op de kaartjes staat in `prompts/`: `prompts/#snack-01` opent alleen de prompt van snack 1.
